Craxel / Black Forest icon set
==============================

39 icons, grouped as concepts, sectors and actions.

Specification
  Grid          24 x 24
  Stroke        1.6, #2597DA (Blue 600)
  Caps, joins   round
  Fill          none, except three deliberate exceptions:
                intelligence (centre dot), online (signal dot),
                status-dot (centre fill)

Recolouring
  Blue 600 #2597DA on light surfaces
  Blue 500 #38B6FF on dark surfaces
  Swap the stroke attribute, or set stroke="currentColor" to inherit.

order-1.svg uses a live text element in IBM Plex Mono. If the font is not
available where it renders, convert it to outlines.

Provenance
  These are redrawn by eye from two screenshots of an existing library,
  not exported from the original source. They are close but not identical.
  Treat as a working reference rather than the master set.
